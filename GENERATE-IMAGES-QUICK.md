# 🎨 Rychlý návod - Generování obrázků

## ⚡ 5 KROKŮ K HOTOVÉ EPIZODĚ

### Krok 1️⃣: Registrace na OpenArt AI
```
👉 Jděte na: https://openart.ai/
👉 Klikněte: "Sign Up" nebo "Get Started"
👉 Registrujte se (zdarma nebo placený plán)
```

### Krok 2️⃣: Základní nastavení
```
Po přihlášení:
- Klikněte "Create"
- Model: Stable Diffusion XL
- Size: 1024x1024
- Steps: 30-40
- CFG Scale: 7-8
```

### Krok 3️⃣: Negative Prompt (ZKOPÍRUJTE A POUŽIJTE PRO VŠECHNY)
```
ugly, distorted, blurry, low quality, bad anatomy, poorly drawn hands,
deformed, mutation, extra limbs, modern style, photographic, realistic photo,
horror, scary, dark atmosphere, violence, adult content, text, watermark
```

## 💡 PRO TIP: Rychlejší workflow

### Použijte "Batch Mode" (pokud dostupné):
1. Vložte všechny prompty najednou
2. Nechte generovat během noci
3. Ráno vyberte nejlepší

### Nebo generujte po skupinách:
1. **Ráno:** Character sheets + Stránka 1-2
2. **Odpoledne:** Stránka 3-5
3. **Večer:** Stránka 6-8
4. **Druhý den:** Stránka 9-10 + výběr variant
